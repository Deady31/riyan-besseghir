# Riyan Besseghir — Portfolio

Personal portfolio of Riyan Besseghir, AI Product Manager.

**Stack:** React 19, TypeScript, Vite, Tailwind CSS 4, GSAP (ScrollTrigger, SplitText), Lenis, and a hand-written WebGL shader that redraws the hero portrait as a living halftone.

**Features**

- Bilingual (FR / EN), following the browser language, with the choice remembered
- Interactive halftone portrait that reacts to the cursor and morphs into a key figure on scroll
- Live chatbot ([Méca-Riyan](https://riyan-cv-chatbot.vercel.app)) embedded in a code-drawn iPhone frame
- Filterable index of 35 projects with cursor-following previews
- Respects `prefers-reduced-motion`

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
